# Contexto — robots.txt
#
# El foso es el DATO POR DIRECCIÓN (/a/ y /s/), no la explicación del método.
# Bloquear la explicación no protege nada y cuesta descubrimiento. Por eso los
# agentes se separan en dos grupos:
#
#   ENTRENAMIENTO → bloqueo total. No hay razón para regalar el corpus.
#   RESPUESTA     → pueden leer marca y método; el catastro sigue cerrado.
#
# Excepción transversal: /llms.txt y /.well-known/ quedan legibles para TODOS,
# incluso para los bloqueados. Ese manifiesto es el que declara qué NO debe
# citarse (tráfico y cobertura vegetal no tienen fuente). Un agente que no puede
# leerlo es más peligroso, no menos.
#
# Nota: los nombres de estos agentes cambian con el tiempo. Revisar cuando se
# toque este archivo — un agente nuevo cae en "User-agent: *" por omisión.
