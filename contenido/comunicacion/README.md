# Sistema de comunicación de Contexto AI

Estado: **v0.1 · experimental**

Este directorio convierte la ejecución real de Contexto y la vigilancia estratégica semanal en una disciplina de comunicación medible. El objetivo no es publicar por publicar: es descubrir qué ideas, pruebas y posiciones de Contexto generan comprensión, resonancia y consecuencias útiles para el negocio.

## Principio operativo

**Evidencia → selección editorial → hipótesis → publicación → medición → aprendizaje → siguiente experimento.**

La comunicación no puede modificar la verdad técnica ni el plan de ejecución. La jerarquía de fuentes sigue siendo:

1. Repository HEAD/main y evidencia reciente verificable = verdad técnica actual.
2. Plan de ejecución vigente = verdad de ejecución.
3. Blueprint = arquitectura objetivo.
4. Auditorías, handoffs y reportes = fotografías históricas fechadas.

Cuando no exista evidencia suficiente, se etiqueta como hipótesis o se reserva para después.

## Entradas semanales

Dos flujos ya existentes alimentan el sistema:

- **Estado semanal de Contexto** → pruebas, avances, errores, aprendizajes y construcción real.
- **Vigilancia estratégica de IA** → cambios externos, posiciones, comparaciones y tensiones relevantes.

Ambos deben producir al final un bloque `CANDIDATOS PARA COMUNICACIÓN` con un máximo de tres candidatos.

## Salida semanal

La mesa editorial selecciona de 2 a 4 piezas como máximo. Cada pieza debe tener:

- objetivo real;
- audiencia prioritaria;
- hipótesis falsable;
- evidencia disponible;
- tipo editorial;
- capítulo narrativo;
- llamada a la acción o conversación buscada;
- métrica primaria;
- criterio de aprendizaje.

Si una pieza no tiene objetivo o evidencia suficiente, no se publica.

## Tipos editoriales

- **PRUEBA**: algo que ocurrió y puede demostrarse.
- **OPINIÓN**: una posición propia que puede ser discutida.
- **ENSEÑANZA**: un mecanismo o método útil para la audiencia.
- **HISTORIA**: una escena real con tensión, decisión o coste.
- **OFERTA**: una invitación explícita a probar, conversar, integrar o trabajar juntos.

## Métrica principal

No optimizamos por impresiones. Usamos tres niveles:

**Atención → Resonancia → Consecuencia.**

La consecuencia pesa más: conversación cualificada, mensaje relevante, reunión, alianza, integración, aprendizaje de mercado o evidencia que refuerza/contradice una hipótesis.
